# Title: Simple Network 
# Subject: Introduction to Data Communication and Networking

## Overview

The project aims to enhance understanding of data communication and networking concepts by simulating a real-world network. A star topology is used, where a central router connects multiple devices such as PCs, laptops, servers and access points. The network includes both wired and wireless connections, along with services like FTP (File Transfer), DNS (domain name resolution), and Email communication. 

## Objectives

1. To learn how to set up wired and wireless networks
2. To share files between devices using command prompt
3. To test connectivity using ping commands
4. To identify IP addresses and connected devices
5. To send messages via email within the network
6. To understand network simulation using Packet Tracer
