# Title: Bank Marketing Campaign
## Subject: Introduction to Machine Learning

## Overview

Bank Marketing Campaign dataset was downloaded from Kaggle platform by VOLODYMYGAVRYSH which provides valuable insights into marketing campaigns conducted by a financial institution. This dataset includes information on various attributes such as client demographics, communication channels, and campaign outcomes, offering a comprehensive view of the marketing strategies employed. 

## Problem Statement

The Bank Marketing Campaigns Dataset provides an opportunity to analyze the effectiveness of marketing campaigns conducted by a financial institution.

## Objectives

1. To predict the factors that indluence whether a client subscribes to a term deposit using BPNN classification algorithm
2. To compare model using parameter such as learning rate, number of epoch, number of training set, activation function and optimizer. 

## Conclusion

In conclusion, we were be able to predict the factors that influence whether a client subscribes to a term deposit using BPNN classification algorithm and compare model using parameter such as learning rate, number of epochs, activation function and optimizer which we can conclude that the learning rate (0.01, 0.1, 0.3, 0.5 and 0.9) with highest accuracy 0.8865, number of epochs 200 with highest accuracy 1.0000,  Linear activation function with highest accuracy 0.8967.
